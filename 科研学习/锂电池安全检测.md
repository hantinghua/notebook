# EIS技术
电池电阻表示形式复杂，需要复数阻抗（交流阻抗）表示
施加交流，测量电池电流电压响应，得出Nyquist图，拟合等效电路（Rs，Rct，Cdl）
不同频带电池内部主导物理过程不同（未做）

# MCU功能（STM32F103C8T6）
生成激励（接收上位机频率）-同步采样（DMA，1600）-取直流分量，注入补偿电压-FFT阻抗分析（输出阻抗模与阻抗相位）-发送到上位机（Nyquist图）-拟合等效电路（未做）

# 学长的优化方案
信号发生：主控芯片-DDS频率合成器（ADXX）-运放-高功率运放-howland变换（电压转电流）-输入电池
ADC采样：电池电压电流响应-差分放大器-PGA可编程放大器-ADC模数转换器-经DMA（直接内存访问）到CPU
实时消除直流偏置：PID动态补偿
