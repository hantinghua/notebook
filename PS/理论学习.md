# 钢笔工具
分离图层 钢笔：**ctrl+enter**生成抠图选区
# 图层混合模式
变暗：正片叠底
变亮：滤色
对比度：叠加，柔光
# 蒙版
(烫金字体)剪贴蒙版：上图下形，**ctrl+alt+g**，ctrl+t可调整位置
（优化边缘）图层蒙版：黑色，隐藏；灰色，半透明；白色，橡皮擦，**ctrl+i**反相，**ctrl+enter"生成选区
# 滤镜
用来做图像效果（用得好可以很牛×）
智能对象图层：非常重要，不然效果无法保留
还有注意新建-填入背景，否则效果无法显示
几大重要滤镜，高斯模糊（突出主体），凸出（油画效果），扭曲（很牛×）
投影也可以做出很牛×的效果
# 调色
顾名思义，调节画面颜色
常用的操作：曝光度/亮度，对比度（鲜明），自然饱和度（鲜艳），色相饱和度+色彩平衡（针对单一颜色，两个组合用很强大）
